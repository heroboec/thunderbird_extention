Подключение к нейросети

Адрес OpenAI-совместимого сервера, обычно заканчивается на /v1.

Нажмите «Проверить подключение», чтобы подгрузить список доступных моделей, затем выберите модель в этом поле.

Чем меньше срок, тем быстрее первый поиск цепочки. Поиск идёт только в учётной записи письма; уже найденные цепочки берутся из памяти.

Повторно открытая цепочка без новых писем не отправляется в нейросеть: анализ берётся из памяти.
